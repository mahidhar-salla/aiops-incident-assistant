# Contributing

Thanks for taking a look. Issues and small PRs are welcome.

```bash
make install   # creates .venv with dev tools
make ci        # what CI runs: ruff, mypy, pytest, stale-data check, offline demo
```

- Synthetic data only. Never add real logs, even redacted ones.
- Incidents are generated by `src/aiops_assistant/synth.py`. Change the generator, run `make data`, and commit the updated `incidents/`; CI fails if they're stale.
- New incident types need a runbook in `runbooks/` and a label with key lines.
- If you change the prompt or a backend, include `make eval` output in the PR.
